# Changelog

## 0.8.0 — 2026-08-22

Первый публичный beta-релиз:

- мастер установки на чистый Ubuntu 24.04 VPS без обязательного платного домена;
- бесплатный HTTPS-адрес из публичного IP через `sslip.io`;
- ежедневные проверяемые резервные копии и безопасное обновление с откатом;
- все URL и маркер, необходимые для Meta, доступны в экране подключения;
- GitHub Actions проверяет каждый push, а сервер сопровождающего обновляется только после тестов;
- исправлены зоны нажатия чипов, отступы действий правил и Linux line endings деплоя;
- полная русская инструкция для пользователя без опыта разработки.
